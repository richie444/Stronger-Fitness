# Stronger Fitness

A responsive fitness studio website built with React, Vite, and Tailwind CSS.

## Run locally

1. Install Node.js (version 20.19+ or 22.12+).
2. Run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

## Features

- Class schedule filtering by training category.
- Reusable, controlled booking stepper on every class card.
- Hardcoded class, coach, and membership content in `src/data/siteData.js`.
- Responsive layouts styled with Tailwind utility classes.

Class and coach photography is served by Unsplash.
